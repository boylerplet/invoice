# memory-bank

Source of context for any new Claude session. Read in this order:

1. `progress.md`: what is done, what is next, known issues. **Update it at the end of every work chunk.**
2. `context.md`: environment, repo map, commands, gotchas.
3. `architecture.md`: how the pieces fit (data flow, key modules, where to change what).
4. `testing.md`: gates, unit and e2e harness, QA scripts.
5. `next-steps.md`: backlog and ideas that are not built.
6. `../CLAUDE.md` (rules that must never be broken), `../docs/BUILD_PROMPT.md` (full spec), `../docs/DECISIONS.md` (every assumption made, one line each), `../docs/TEMPLATE_CONTRACT.md`, `../README.md`.
